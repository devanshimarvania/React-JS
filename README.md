# 🚀 React Explorer – Project Summary

**React Explorer** is an interactive React learning project built using **Vite + React**.
It demonstrates all core React concepts through simple, clear, real-time examples.
The project contains multiple individual components—each representing a specific React concept—rendered dynamically inside the main `App.jsx`.

---

## 📌 Core Features & Modules Included

### ✔ 1. JSX Module

* Demonstrates JSX syntax, expressions, variables, and rendering UI elements.
* Example: printing names, IDs, and dynamic values using JSX.

### ✔ 2. Props Module

* Shows how data is passed from parent to child components.
* Includes examples of renamed props (`heading`, `content`, etc.).

### ✔ 3. State Module

* Interactive counter using `useState`.
* Shows real-time state updates and re-rendering behavior.

### ✔ 4. List Rendering Module

* Renders arrays with `.map()`
* Uses different variable names and updated fruit list.
* Includes unique keys for each list item.

### ✔ 5. Form Handling Module

* Controlled components using `useState`.
* Handles form input updates & submission events.
* Displays submitted values instantly.

### ✔ 6. Lifecycle & useEffect Module

* Demonstrates component lifecycle:

  * Mounting
  * Updating
  * Unmounting
* Includes interval timer with cleanup (`clearInterval`).

### ✔ 7. Class Component Module

* Shows React class component structure:

  * constructor
  * state
  * this.setState()
  * event handling
