### 🔍 Enhanced Employee Table Features

The **View Employee** module has been enhanced with advanced data interaction capabilities to improve usability and data exploration:

* **Real-time Search**: Instantly filter employees by name with case-insensitive search as the user types.
* **Sorting Options**:

  * Name (A → Z)
  * Name (Z → A)
  * Salary (Low → High)
  * Salary (High → Low)
* **Status Filtering**:

  * View all employees
  * Show only Active employees
  * Show only Inactive employees

All operations are handled using **derived state**, ensuring the original employee data remains untouched.
Search, sort, and filter work **together seamlessly**, delivering a smooth and responsive user experience while maintaining clean, maintainable React code.
