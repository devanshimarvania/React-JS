**🚀 Task Builder Application – React + Redux Toolkit**

**📌 Project Overview**

Task Builder Application is a sleek and modern **React.js + Redux Toolkit** project designed to showcase **powerful global state management** in a simple yet practical way. The app allows users to **add tasks, mark them as completed with a checkbox, and delete them**, all while maintaining a **centralized and predictable data flow** using Redux.

This project focuses on clean architecture, reusable components, and an intuitive UI, making it a perfect learning example for understanding how **React and Redux work together in real-world applications**. No backend is used — everything runs smoothly on the frontend ⚡

---

**✨ Key Features**

* ➕ Add new tasks instantly
* 🗑️ Delete tasks with one click
* ☑️ Mark tasks as completed using checkbox
* ✏️ Automatic line-through styling for completed tasks
* 🔄 Real-time UI updates via Redux state
* 🧩 Modular and scalable folder structure
* 🎨 Modern, responsive, and clean CSS design

---

**🛠️ Tech Stack**

* **React.js** – UI Development
* **Redux Toolkit** – Global State Management
* **React-Redux** – Store Integration
* **JavaScript (ES6+)** – Logic & Interactivity
* **HTML & CSS** – Structure & Styling

---

**🎯 Purpose of the Project**
Built as a hands-on demonstration of **predictable state flow, component communication, and scalable frontend architecture**, this application helps learners and developers understand how professional React apps manage shared data efficiently.
