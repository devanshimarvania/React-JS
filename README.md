# 📚 Student Activity Manager

A React-based interactive mini-project designed to help learners practice core React concepts including events, conditional rendering, state management, refs, and argument passing.

---

## 📌 Project Overview

**Student Activity Manager** allows users to add students, view/toggle their details, mark attendance, and delete records — all handled through React state without any backend or storage.

This project is ideal for beginners learning component structure, props, events, and dynamic UI updates.

---

## 🧱 Features

### ✔ Add New Students

* Form validation
* Autofocus and ref-based input handling

### ✔ Manage Student List

* View all added students
* Delete students
* Mark **Present / Absent**

### ✔ Conditional Rendering

* “No Students Found” message
* Toggle details
* Status badges
* Validation errors

### ✔ React Concepts Covered

* Events (onChange, onClick, onSubmit)
* Passing arguments in event handlers
* State management using `useState`
* Refs (`useRef`) for focus management
* React Fragments
* Props + Component communication
* List rendering (`map`, keys)
* ES6 features: spread, arrow functions, destructuring

---

## 🛠 Tech Used

* **React + Vite**
* **Bootstrap** (UI Styling)
* **Pure React State** (No backend, no localStorage)

---

## 🎯 Purpose

This project helps students learn how React components interact using **state + props**, and how UI updates instantly with event-driven rendering — without using any backend or storage.
