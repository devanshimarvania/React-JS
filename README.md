# LocalBox Miner

## 📌 Project Overview

**LocalBox Miner** is a **React-powered offline data management dashboard** designed to demonstrate practical front-end development skills. It enables users to **add, edit, and delete records** while persisting data entirely in the browser using **localStorage**, simulating real-world offline-first tools without any backend.

This project highlights best practices in **state management, component communication, event handling, and responsive UI design**.

---

## 🧩 Key Features

* **Full CRUD Functionality**: Add, edit, delete, and clear student records.
* **Persistent Storage**: Data is saved in the browser via `localStorage` for offline access.
* **Dashboard Summary**: Quick overview of total records and the most recently added entry.
* **Event-Driven Interface**: Handles `onChange`, `onSubmit`, and `onClick` events seamlessly.
* **Form Validation**: Inline feedback for required fields and email formatting.
* **Conditional Rendering**: Dynamic UI for empty states, edit mode, validation messages, and bulk delete confirmations.
* **Responsive Design**: Clean, mobile-friendly layout using **Bootstrap 5**.

---

## ⚡ Technologies Used

* **React** (Functional Components & Hooks)
* **Bootstrap 5** for responsive UI
* **JavaScript (ES6+)**
* **localStorage** for persistent offline data
