# 📋 Customer Feedback & Issue Reporting System

The **Customer Feedback & Issue Reporting System** is a fully functional React-based application designed to collect structured feedback, complaints, bug reports, and improvement suggestions from users. It simulates real-world support ticket systems used in SaaS platforms, CRM portals, and enterprise dashboards.

This project demonstrates **industry-level form handling**, **dynamic fields**, **validation**, and **state management** — making it perfect for learning or showcasing professional React skills.

---

## 🚀 Features

### ✅ **1. Interactive Feedback Form**

Collects detailed user information:

* Full Name
* Email
* Issue Category (Bug, Complaint, Suggestion, Other)
* Priority Level (Low, Medium, High)
* Issue Description
* Screenshot URL *(uncontrolled input)*
* Additional Notes *(uncontrolled textarea)*

Includes **dynamic add/remove fields**:

* Steps to Reproduce
* Suggested Improvements

---

### ✅ **2. Controlled & Uncontrolled Components**

Uses both professionally:

* **Controlled:** Name, Email, Category, Priority, Description, Steps, Suggestions
* **Uncontrolled (Refs):** Screenshot URL, Additional Notes

This mirrors real-world systems where required fields are controlled and optional fields use refs.

---

### ✅ **3. Real-Time Validation**

* Required fields
* Email format checking
* Minimum description length
* Category & priority validation
* Red error highlights
* Disable submit until form is valid

---

### ✅ **4. Clean & Modern UI**

* Card-based layout
* Consistent spacing & padding
* Input focus highlights
* Error styling
* Responsive mobile-friendly design

---

### ✅ **5. Feedback Dashboard**

After submitting, the system displays:

* User information
* Category & Priority badges
* Description
* Screenshot preview
* Steps to reproduce
* Suggested improvements
* Submission timestamp

Uses:

* List rendering
* Conditional rendering
* Component-based structure

---

## 🎯 Learning Outcomes

By building this project, you will learn to:

* Build complex React forms
* Use controlled & uncontrolled components
* Manage dynamic form rows
* Apply real-time validation
* Use React state & event handling professionally
* Build reusable UI components
* Create clean dashboards for user-generated content
