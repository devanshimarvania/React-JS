# 🌟 Employee Management System (React.js)

**A modern, full-featured Employee Management System built with React.js and Bootstrap 5.**
Manage your employees efficiently with a clean, responsive, and interactive UI — all powered by **React Hooks** and **local storage**.

---

## 🚀 Features

* **🏠 Home Page:**
  Dynamic employee cards showing **photo, name, department, designation, and status**.

* **➕ Add Employee:**
  Intuitive form to add new employees with **validation and image upload**, storing data in local storage.

* **📋 View Employee:**
  Interactive table with **Edit** and **Delete** functionality for managing employee records.

* **✏️ Edit Employee:**
  Pre-filled form to update employee details: **name, phone, designation, salary**.

* **🧭 Navigation:**
  Seamless routing using **react-router-dom**.

* **💡 State Management:**
  Dynamic UI updates using **useState** and **useEffect**.

* **🎨 UI/UX:**
  Modern, clean, and responsive design using **Bootstrap 5**, with consistent spacing and attractive card layouts.

---

## 🛠 Technical Stack

* **Frontend:** React.js
* **Styling:** Bootstrap 5
* **Routing:** react-router-dom
* **State Management:** React Hooks (`useState`, `useEffect`)
* **Data Persistence:** Local Storage
