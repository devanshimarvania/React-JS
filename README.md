# 🌸 Gmaakeup Makeup Studio — Homepage (React + Bootstrap 5)

This project is a **fully responsive homepage** for a professional makeup studio, built using **React JS** and **Bootstrap 5**.
The layout and styling are inspired by the “GMAakeup” HTML theme, but recreated from scratch using **modern React components**, **map functions**, and **reusable UI sections**.

The goal of this homepage is to present a clean, elegant, and high-quality makeup studio brand with visually engaging sections, smooth layout, and organized components.

---

## ✨ Key Features

### ⭐ 1. Responsive Hero Banner

A clean hero section with a studio introduction, call-to-action button, and high-quality images optimized for all screen sizes.

### ⭐ 2. Services Section (Using Map Function)

A dynamic services grid built with **React map()**, where images and titles are imported from the `assets` folder and rendered as **Bootstrap 5 cards**.

### ⭐ 3. About Section

Professional “About Me” / “About Studio” section describing the makeup artist, skills, experience, and values.

### ⭐ 4. Work Gallery with Tabs (Filter)

A **Bootstrap 5 Nav Pills**–based gallery:

* All
* Eye Makeup
* Hair Style
* Bridal
* Party Makeup

Images are loaded using **map()** and filtered based on category.
Each image uses sharp corners, equal height, and responsive grid alignment.

### ⭐ 5. Testimonials Carousel

A modern testimonial slider created using Bootstrap 5 carousel, displaying client reviews with images, names, and feedback.

### ⭐ 6. Latest News / Blog Cards

A blog/news section built with **map()**, featuring:

* Imported images
* Admin/date icons
* Post title (anchor tag)
* Short description
* Read More button

### ⭐ 7. Footer Section

A minimal and elegant footer including links and contact details.
